# STOMS-SBV1-BOS-IME
### STOMS Business Operating System — Inventory Management Engine (BOS-IME)

A high-performance, enterprise-grade inventory and stock management desktop suite built on modern **.NET 8 WPF** architecture for ultra-fast warehousing, SKU lifecycle tracking, and seamless supply-chain operations.

## 📦 Planned Core Capabilities

- **Real-Time Stock Engine:** Multi-warehouse inventory inward, outward, and transfer ledger.
- **SKU & Barcode Integration:** Rapid barcode scanning, custom SKU generation, and batch/lot allocation.
- **Expiry & Re-order Alerts:** Automated threshold triggers for low stock levels and expiring batches.
- **Relational Data Safety:** Air-gapped offline relational database storage with instant verification.
- **STOMS ERP Sync:** Native synchronization with **Signatures Light Bill ERP** and **STOMS Ecosystem**.

## 🛠️ Getting Started

### Prerequisites
- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Visual Studio 2022 (with .NET Desktop Development workload) or VS Code / JetBrains Rider.

### Build and Run
```bash
# Clone the repository
git clone https://github.com/Saumya25-hub/STOMS-SBV1-BOS-IME.git

# Navigate to project directory
cd STOMS-SBV1-BOS-IME

# Restore dependencies
dotnet restore

# Build the solution
dotnet build

# Launch the application
dotnet run --project STOMS-SBV1-BOS-IME.csproj
```
